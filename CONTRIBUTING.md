# Contributing to Linux Spectre

Contributions are welcome after the repository is publicly opened. Please begin with a GitHub issue describing the problem and reproducer. Use a feature branch and a focused pull request. Include validation commands, screenshots for UI changes, license and provenance information for copied files, and regression coverage where practical. Never submit private credentials, exploit targets, customer data, or unauthorized scans.

Maintainer approval is required before a change enters a tagged release. Container, kernel, installer, and build-script changes must be staged and tested before being considered for production. Security vulnerabilities should be reported privately according to `SECURITY.md`.
