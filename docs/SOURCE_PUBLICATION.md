# Source publication status

As of 2026-10-11, this repository is being prepared for source publication. The complete Linux Spectre OS master source has **not yet been uploaded**.

## Required to publish the complete OS

- Audited master source for installer, ToolHub, branding and build scripts.
- Corresponding custom Linux kernel source, configuration and patch lineage.
- Third-party package list, notices and accurate license attributions.
- Source/build inputs sufficient for fresh-clone reproducible assembly. In particular, eliminate or document lawful access to the historical recovery ISO and ext4 baseline used in the qualified private build.
- Oracle Guest Additions 7.0.16 corresponding notices/source and actual rights review, or an alternative freely redistributable integration.
- No passwords, tokens, private keys, proprietary material without permission or developer-private files.
- Clean install and regression test from the published build process.

**Do not treat the ISO checksum alone as proof of source reproducibility or rights clearance.**
