# Linux Spectre — Code-only source preview

This branch contains a partial Linux Spectre GNOME and
Spectre ToolHub source snapshot.

Forty unreviewed graphical assets are intentionally excluded.

This is not a complete, buildable Linux distribution.
The original kernel source, private ISO build dependencies,
and third-party redistribution requirements remain unresolved.

Excluded graphics may be required for normal installation
and runtime operation.

Source-code copyright and license review must be completed
before this branch is approved for public publication.
