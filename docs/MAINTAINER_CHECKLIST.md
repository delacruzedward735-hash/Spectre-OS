# Maintainer publication checklist

- [ ] Owner account for repository has push/maintain access and protected `main`
- [ ] Read-only source audit completed and report reviewed
- [ ] Scan every file planned for the public Git tree including generated assets and history
- [ ] Original components' license choices approved; no license assigned to code the maintainer does not own
- [ ] Kernel corresponding source, config, module patches and toolchain documented
- [ ] Build no longer requires undocumented private/historical ISO or ext4 baseline inputs
- [ ] Oracle VirtualBox Guest Additions rights/notices/source obligations cleared or replaced
- [ ] Software bill of materials and distribution notices generated
- [ ] Fresh clone full ISO build and installation tested
- [ ] Signed or SHA-256 validated release artifact published separately, never committed to Git tree
- [ ] Maintainer approves release promotion
